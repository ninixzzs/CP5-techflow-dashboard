Aplicação web interativa para um restaurante de gastronomia japonesa autêntica, desenvolvida com **React**, **Vite**, **Tailwind CSS** e **React Router DOM**. O projeto apresenta uma interface responsiva, moderna e orientada a Dark Mode, com visualização de cardápio dinâmico, filtragem por categorias e identidade visual própria com a mascote Maneki-neko (gato da sorte) 🐱🌸.

---

## 🚀 Funcionalidades

- **🏠 Home Completa:**
  - *Hero Section* com chamada para ação e apresentação dos diferenciais do restaurante.
  - Seção de destaques do cardápio gerados dinamicamente.
  - Avaliações e depoimentos de clientes.
  
- **📖 Cardápio Interativo:**
  - Filtragem de pratos por categoria (*Sushis, Sashimis, Quentes, Sobremesas*).
  - Cards de produtos reutilizáveis com imagens dinâmicas via URL e formatação de preços em Real (R$).
  
- **🎨 Interface & Usabilidade:**
  - Design limpo e moderno em *Dark Mode*.
  - Navegação responsiva com menu hambúrguer para dispositivos móveis.
  - Logótipo personalizado com o Maneki-neko.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/)** — Biblioteca para construção de interfaces baseadas em componentes.
- **[Vite](https://vitejs.dev/)** — Build tool ultra-rápida para o ambiente de desenvolvimento.
- **[Tailwind CSS](https://tailwindcss.com/)** — Framework utilitário para estilização responsiva e ágil.
- **[React Router DOM](https://reactrouter.com/)** — Gerenciamento de rotas e navegação SPA (*Single Page Application*).

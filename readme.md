> Check Point 5 (CP5) — Front-End Web Development / Software Engineering (FIAP)

Aplicação web interativa desenvolvida para um restaurante de gastronomia japonesa autêntica, criada com **React**, **Vite**, **Tailwind CSS** e **React Router DOM**. O projeto apresenta uma interface moderna, responsiva e com suporte a temas visuais, incluindo a exibição de cardápio dinâmico e componentes reutilizáveis.
